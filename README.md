# Professional CV & Resume Generation Suite

An automated toolset to generate beautifully formatted, ATS-friendly, and multi-format Curriculum Vitae (CV) and resumes.

## Features
- **Multi-Format Output**: Compiles responsive HTML templates directly to pixel-perfect PDF and Microsoft Word DOCX files.
- **International & Regional Variants**: Includes tailored configurations for International, Egypt, and targeted executive formats.
- **Automated Puppeteer/Selenium Rendering**: High-fidelity CSS pagination and layout controls.
- **Preview Assets**: Pre-rendered visual previews and document assets.

## Usage
```bash
python build_cv.py
python generate_pdf.py
python generate_docx.py
```
